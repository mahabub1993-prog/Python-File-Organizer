# FILE ORGANIZER
### Windows Desktop Application
**Version:** 1.0

## Project Overview
File Organizer is a Python-based desktop automation tool designed to organize files automatically according to their extensions.

It provides a simple graphical user interface (GUI) for previewing, organizing, and reporting file operations.

## Main Features
- Easy-to-use graphical interface.
- Automatic file classification.
- Preview before organizing.
- Duplicate filename protection.
- CSV report generation.
- Recursive file scanning.
- Safe file movement with confirmation.

## Supported File Categories
- PDF Files
- Images
- Spreadsheets
- Documents
- Videos
- Audio
- Compressed Files
- Programs
- Presentations
- Others

## How to Use
1. Run FileOrganizer.exe.
2. Select a folder using Browse Folder.
3. Click Preview Files.
4. Review the file organization plan.
5. Click Organize Files.
6. Export the CSV report.
